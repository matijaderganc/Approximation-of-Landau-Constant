# Approximation of Landau Constant
## Programiranje 2 project

The goal of the project is to calculate the Landau constant to the best precision so far. More about the constant and the algorithm can be found in Robert Rettinger's article available [here](https://lmcs.episciences.org/1189/pdf). Put shortly, the constant gives us the largest circle to fit inside the image of the unit circle with any normalised holomorphic function.

So far, we have implemented Dyadic numbers for efficient computation, a psi function to represent holomorphic functions and a struct of holomorphic functions. We will then take images of the unit complex disk and calculate the area of the largest disk inside the image using an EDT algorithm. We have also implemented epsilon-covering grids that will help us calculate this. The computations will be parallelized with Tokio to save time.

# Results
The algorithm has been, for the most part, successfully implemented. We are able to run and approximate the constant up to the first step of precision, getting the result of approximately 0.5, not far from 0.5432... (actual value). We do however, run into issues. Epsilon value Lemma 6 of the article suggests quickly become really small, even at the first steps of precision. This results in grids with billions of points, which are impossible to store on RAM. We would hope to reduce those bounds so we could run more computation, but that would require theoretical progress.

We also tried approaching the constant slightly independent of algorithm by plotting whole unit disks and evaluating lambda_f for many function, but sadly, results were no better than 0.8, as the m sequence suggested in the article results in images too large for words with reasonable amounts of letters. We also cannot check for all word, lets say 100, as 4^100 is beyond our computational reach regardless of efficiency.

# UI Instructions
We have created an UI experience using Axum for users. It is available by opening the running the code in `main.rs` using the following command in a terminal inside the folder
```bash
cargo run --release
```
The code will display a link, which the user can open using `ctrl+click`. The UI has multiple function: in the first one, they can select their own word and disk accuracy, then evaluate the size of the largest disk inside the image of the function generated by the word. The next window offers users a chance to approximate Landau's constant on their own, selecting desired word length and precision step, while the introduction page offers a short summary of Landaus constant as the methods used in this project as well as a quick guide to reading domain colored plots.

# Tests
Numerous tests are included in the files to ensure proper functionality of the code as well as warn developers of any bugs which may suddenly be present. The tests are located in `tests/` and cover a number of dyadic, holomorphic, evaluation and EDT tests. The tests can be executed by using 
```bash
cargo test
```
